# My First Git Project 🚀

Учебный проект для освоения Git и GitHub.

## Описание

Простая HTML-страница, созданная для изучения основ командной разработки с Git.

## Структура проекта

```
test/
├── index.html      # Главная страница
├── style.css       # Стили
├── README.md       # Этот файл
└── .gitignore      # Список файлов исключённых из Git
```

## Как запустить

Откройте `index.html` в браузере.
